# Algorithm Visualization Laboratory

An interactive web laboratory for understanding algorithms through experiments, not just final answers.

## Experiments

- **Evolutionary game theory** - Explore cooperation, defection, genetic strategies, selection, mutation, and population dynamics through a repeated Prisoner's Dilemma.
- **Multi-robot coordination** - Watch task allocation, path planning, reservations, and deadlock resolution in a dynamic warehouse.
- **Traveling salesman problem** - Compare genetic search, simulated annealing, and 2-opt local improvement as routes converge.
- **Neural network classification** - Follow forward propagation, loss calculation, gradients, and decision-boundary updates.
- **Q-learning maze** - See exploration, exploitation, temporal-difference updates, and policy formation.
- **Boids swarm intelligence** - Observe how separation, alignment, and cohesion create collective behavior from local rules.

## What you can do

- Change parameters and see their effects immediately.
- Run simulations step by step.
- Inspect algorithm principles and intermediate calculations.
- Compare different strategies on the same problem.
- Choose Chinese or English when entering the laboratory.

## Technology

Built with React, TypeScript, Vinext, and CSS. The simulations run directly in the browser and are designed for visual, experiment-driven learning.
